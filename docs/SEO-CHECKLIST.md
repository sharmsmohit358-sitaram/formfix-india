# SEO checklist
Done: unique titles/descriptions, one H1 per page, semantic HTML, canonicals from PUBLIC_SITE_URL, dynamic sitemap.xml, robots.txt, breadcrumb nav, Open Graph, JSON-LD Organization/WebSite/WebPage (no fabricated reviews/ratings), 404 page, no thin keyword pages (six tools have distinct behaviour).
Owner actions before/after launch: set PUBLIC_SITE_URL to the real domain and rebuild; verify the domain in Google Search Console (meta tag via PUBLIC_GOOGLE_SITE_VERIFICATION); submit sitemap.xml; check Indexing report; do not publish placeholder-domain canonicals.
